# Chess

A simple two-player chess game in the browser (HTML, CSS, JavaScript).

## Play

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Features

- Full piece movement rules (pawn, knight, bishop, rook, queen, king)
- Turns, captures, and pawn promotion to queen
- Check, checkmate, and stalemate detection
- Click a piece, then a highlighted square to move
- New game button
